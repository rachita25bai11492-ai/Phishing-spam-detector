🔐 Cybercrime Detection System (Rule-Based AI)
📌 Project Title
Cybercrime Detection System Using Rule-Based Artificial Intelligence
________________________________________
📖 Project Overview:
This project is a simple yet effective Cybercrime Detection System that identifies whether a message is safe, suspicious, or fraudulent.
With the rise in online scams such as phishing, fake offers, and OTP frauds, this system helps users quickly analyse messages and avoid potential cyber threats.
The system uses a rule-based Artificial Intelligence approach, where predefined suspicious keywords are used to classify the message. It is lightweight, fast, and does not require any external libraries.
________________________________________
✨ Features:
•	✅ Detects spam and fraud messages
•	⚠️ Classifies messages into:
o	Safe
o	Suspicious
o	High Risk Fraud
•	⚡ Fast and lightweight (no external libraries required)
•	💻 Runs on any Python-supported system
•	🧠 Uses basic AI logic (rule-based decision system)
________________________________________
🛠️ Technologies / Tools Used:
•	Programming Language: Python
•	Platform: VS Code / Visual Studio / Any Python IDE
•	Concept: Artificial Intelligence (Rule-Based System)
________________________________________
⚙️ Steps to Install and Run the Project:
1. Install Python
Make sure Python is installed on your system.
Check using:
python --version
2. Save the Code
Save the project file as:
cyber_detection.py
3. Run the Program
Open terminal or command prompt and run:
python cyber_detection.py
